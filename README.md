# Рейс — личный планировщик путешествий

Веб-приложение в одном HTML-файле: поездки, бюджет, маршрут по дням, ссылки на поиск билетов и жилья, список вещей и климатическая справка по 27 направлениям.

**Открыть:** https://gulnazilyasova02-dev.github.io/reys/

## Разделы

Обзор · AI-помощник · Поездки · Направления · Бюджет · Маршрут · Отели и билеты · Список вещей · Погода

## Как устроено

- Один файл `index.html`: CSS и ванильный JavaScript, без сборки и сервера.
- Данные хранятся только в `localStorage` вашего браузера (ключ `reys_travel_v1`).
- AI-помощник работает только в версии, опубликованной внутри Claude (возможность `sample`). На GitHub Pages вместо него показывается сообщение, остальные разделы работают полностью.
- Погода — климатическая норма по месяцам, а не прогноз.

Требования к продукту — в [PRD.md](PRD.md).
